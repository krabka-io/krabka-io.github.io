Verify a chart

The chart signing public key lives in krabka-io/tooling, at charts/krabka-charts.pub.asc.

Key: Krabka Charts <charts@krabka.dev>
Fingerprint: 74A6 7D5C F9AE 199A 45D2  2E42 594B D543 4544 D339
Check the fingerprint before you trust the key. Any earlier key is revoked.

curl -fsSLO https://raw.githubusercontent.com/krabka-io/tooling/main/charts/krabka-charts.pub.asc
gpg --import krabka-charts.pub.asc
gpg --fingerprint charts@krabka.dev
gpg --export charts@krabka.dev > krabka-keyring.gpg
helm install my-op krabka/krabka-operator --verify --keyring ./krabka-keyring.gpg
